How this works, and what it can't do

Your code runs inside your own browser, on your own machine. Nothing is uploaded and nothing is saved to a server. That is why it is instant and free — and also why it is JavaScript rather than Python.

A browser can run JavaScript because every browser already contains a JavaScript engine. It cannot run Python, because there is no Python inside your browser. Running Python properly needs Python installed on your computer — which is exactly what Lesson 1 of Your First Program walks you through.

The good news from Choosing Your First Language: loops, variables and conditions work the same way in both. What you practise here transfers.
